# Company, Employee & Department API

## Description
An ASP.NET Core Web API project for managing company-related data, including employees and departments.

## Technologies Used
- C#
- ASP.NET Core Web API
- SQL Server 
- Entity Framework Core 

## Features
- Manage company data.
- Manage employee data.
- Manage department data.
- Support API operations for retrieving and modifying data.
